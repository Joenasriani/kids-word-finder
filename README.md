# Word Finder

**Status:** original bilingual browser word search game  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

Word Finder is an educational word search game for children with progressive grids, English and Arabic play, touch interaction and responsive browser support.

## Gameplay

Players trace hidden words in a letter grid. The game progresses through eight levels, expanding from small grids to larger challenges.

## Features

- English and Arabic modes
- right to left Arabic layout
- progressive 3x3 to 10x10 grids
- touch and mouse word selection
- overlapping word color blending
- animated SVG mascot
- mobile and desktop layouts

## Technology

HTML5, JavaScript, Tailwind CSS and SVG.
