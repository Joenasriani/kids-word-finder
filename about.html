WORD FINDER

Play the game · Source repository

Game rule

Each level places three target words into a square letter grid. Words can run horizontally, vertically or diagonally in either direction. Players drag across adjacent letters in a straight line to select a word.

generate grid → place three target words → drag across letters → validate word → find all three → advance

Progression

The grid expands from 3×3 at Level 1 to 10×10 at Level 8. Completing all three words advances the level; completing Level 8 opens the final victory screen.

Language modes

The game has separate English and Arabic word pools. Arabic mode changes interface language and layout direction and renders level/grid numbers with Arabic-Indic digits.

Activation context

This game belongs to the same kids-* game set developed for the multi-game interactive children’s edutainment activation in the UAE.

Evidence boundary

The repository implements bilingual word-search play. It contains no study measuring vocabulary acquisition, reading development, language learning, memory improvement or transfer outside the game.
